# browser-use: הפניה (לא בשימוש בקוד)

- מאגר: https://github.com/browser-use/browser-use
- סקירה: https://deepwiki.com/browser-use/browser-use

## מה זה
ספריית Python בקוד פתוח שמאפשרת למודל שפה (OpenAI, Gemini, Claude ועוד) לשלוט בדפדפן Chrome: לנווט, ללחוץ, להקליד, למלא טפסים ולחלץ מידע. יש לה ממשק Python, שורת פקודה ושרת MCP.

## למה היא לא חלק מהאפליקציה
רופא רכב היא אפליקציית Android (Kotlin) ואתר (React). browser-use היא כלי Python שרץ במחשב או בשרת, לא בטלפון. היא לא מותקנת בריפו, ושום חלק מהאפליקציה לא תלוי בה.

## שימושים אפשריים בעתיד
1. **בדיקות אוטומטיות לגרסת הרשת:** סוכן שעובר על האתר כמו משתמש (הוספת רכב, סריקה מדומה, דו"ח). כל ריצה עולה קריאות למודל שפה.
2. **איסוף מידע מאתרים** (למשל רשימות מוסכים): רק אחרי בדיקת תנאי השימוש של כל אתר. לנתוני רכב ממשלתיים יש ממשק רשמי ב-data.gov.il, עדיף עליו.
3. **אוטומציה של משימות ניהול** (למשל מילוי טפסים ב-Google Play Console): רק בפיקוח, לא עם סיסמאות שמורות בקוד.

## אם מכניסים אותה לשימוש
- בתיקייה נפרדת (`tools/`), עם קובץ תלויות משלה, מחוץ לבניית האפליקציה.
- מפתחות API רק ב-GitHub Secrets, לעולם לא בקוד.
- לבדוק את הרישיון בגרסה שמשתמשים בה.
